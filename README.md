# AIS Ceará — Territorial Intelligence Dashboard

A geospatial web application for exploring the territorial organization of Ceará through **Integrated Security Areas (AIS)**, with municipality-level and intramunicipal geographic layers.

The project focuses on transforming heterogeneous territorial datasets into an interactive, typed and inspectable web experience.

## Why this project matters

Territorial datasets rarely arrive ready for visualization. Names differ across sources, boundaries use different levels of granularity, and some records cannot be mapped one-to-one.

This application addresses that problem through a data-preparation and normalization workflow that supports:

- interactive territorial exploration;
- municipality and neighborhood-level visualization;
- explicit treatment of inconsistent or unmatched records;
- polygon aggregation for territorial areas;
- reproducible preprocessing scripts for selected municipalities.

## Engineering highlights

- **React + TypeScript** front end
- **Leaflet / React Leaflet** for interactive mapping
- GeoJSON-based territorial rendering
- polygon processing with **polygon-clipping**
- dedicated preprocessing scripts for Fortaleza and Caucaia
- typed domain contracts and isolated service layers
- clear separation between raw data, normalized data and UI concerns
- light/dark theme support
- production build with TypeScript validation

## Data model and territorial treatment

The application combines territorial datasets with different spatial resolutions.

- Municipal polygons are loaded from GeoJSON.
- Fortaleza uses neighborhood-level territorial data.
- Caucaia can use intramunicipal units derived from census-sector data.
- AIS polygons are generated by dissolving valid territorial units.
- Records that cannot be matched reliably are surfaced as inconsistencies instead of being silently assigned.

This design choice favors **traceability over forced matching**.

## Data responsibility

Territorial and institutional datasets can change over time. Before any official publication, source versions, institutional nomenclature and territorial definitions should be validated against the current authoritative datasets.
